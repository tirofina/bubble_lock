# r18 손납땜 풋프린트 수정본

기준은 r17 공통 4층 PCB다. MPN·부품 패키지·값·회로·네트·부품 몸체 위치·보드 외곽·기존 배선을 유지하고 패드와 해당 풋프린트 속성을 변경했다. PCB 두께는 기존 1.0mm다. 회로도의 Footprint 속성과 구매표도 수정 풋프린트에 맞췄다.

## 변경

- 수정한 풋프린트 109개.
- KiCad HandSolder 랜드 패턴 35개. 설치된 KiCad 10의 Resistor_SMD / Capacitor_SMD / LED_SMD / Package_TO_SOT_SMD 라이브러리에서 해당 패키지 후보를 사용했다. 보드 배치·모델·표기를 유지하고 로컬 HandSolder.pretty에 실제 적용 형상을 저장했다.
- 나머지는 위치별 간격에 따라 바깥쪽 toe만 연장했다. 부품 안쪽 랜드 경계와 패드 폭은 그대로 두며 최소 0.10mm 단위 후보부터 적용했다.
- J1 USB-C, J2 PH, J3 SH, J10 microSD, J11 AUX는 공간이 있는 접점만 연장했다. J1/J2/J3/J10의 피치 방향 폭과 접점 간격, 기구 고정부·장착홀·하우징 위치는 유지했다.
- L1은 원래 Coilcraft 4020 패키지를 유지한 외측 연장이다. 다른 인덕터 패키지용 HandSolder로 바꾸지 않았다.
- U1/U3/U4/U6/U7/U8/U16은 하단 전극·노출 열 패드·페이스트 창·열 비아를 그대로 유지했다. 열풍기 조립 대상으로 남겼다.
- 공간상 변경하지 않은 부품도 변경표에 사유를 기록했다. 직접 납땜 와이어 홀과 기계 홀은 원래 크기다.

## 패드 선택 조건

적용 후보를 만들 때 같은 면의 부품 몸체·다른 패드·배선·비아·실크와 보드 경계·패드 금지 영역을 반영했다. SMD pad-to-pad 0.15mm, 다른 네트 배선 0.15mm, 비아 0.15mm, 몸체/실크 0.10mm를 기준으로 신규 간격 악화를 피했다. 기존 연결 배선과 비아가 닿던 접점도 유지하는 후보를 사용했다. 전체 후보가 맞지 않으면 개별 패드의 외측 연장 폭을 줄이거나 기존 크기를 유지했다. 보드 가장자리 0.50mm와 공식 또는 기존 코트야드도 적용 조건에 반영했다. 확장한 패드에 맞춰 존을 다시 채웠다.

## 파일

- `privacy_bubble_r18_hand_solder_KiCad.zip`: 회로도·PCB·프로젝트·로컬 풋프린트·참조 3D모델·수정 이력.
- `privacy_bubble_r18_hand_solder_4L_gerber_drill.zip`: 수정본의 구리 4층·마스크·실크·외곽·드릴. 스텐실 파일은 포함하지 않는다. 패키지의 페이스트 창은 KiCad 원본에 보존했다.
- `BOM_PCB_1board.csv`: 동일 MPN 통합 구매표. PCB 1장 기준. 부품번호·실장 수량은 r17과 같다.
- `BOM_by_reference.csv`: 개별 기판 표기 / 실장면 / 실제 풋프린트.
- `hand_solder_changes.csv/json`: 변경 여부, 사용 패턴, 패드별 전후 위치·크기.
- `Views/front.svg`, `Views/back.svg`: 수정 PCB의 구리·실크·Fab·외곽 도면. 뒷면도 PCB 편집기의 위에서 보는 좌표로 표시했다.

기존 r17 공통 PCB와 기존 거버 ZIP은 보존했다. 외장 부품·화면 두 종류·케이스 BOM은 바뀌지 않는다.
