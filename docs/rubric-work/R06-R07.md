## R06 대응

- 저장소 지도의 모든 경로를 `git ls-files`와 파일 존재 확인으로 점검함.
- 빠른 시작 명령은 루트 `package.json`의 `setup`, `test`, `verify`, `demo`, `dashboard`, `events`, `api`와 `pc-mobius/package.json`의 스크립트 이름에 맞춤.
- Windows 준비 사항으로 `git clone -c core.autocrlf=false`와 `PYTHON` 지정(`py -3`)을 안내함. XSD SHA-256 불일치와 Store python stub 문제를 처음부터 피하는 방법임.
- 실제 CSE 실행 절차는 `MOBIUS4_ROOT`, `.local/postgres/connection.json`, `run-handover-real.mjs --keep-running` 뒤 `run-interop-real.mjs`, `run-acp-real.mjs`, `run-location-privacy-real.mjs` 순서로 적음.
- 배포는 Pi Gateway systemd 절차와 중앙 서버 구성(Mobius4, PostGIS, MQTT broker, 통합 API, 웹 BFF)으로 나눔.
- 검증 상태 표는 구현, 로컬 검증, 실물 검증을 분리함. MEC는 로컬 공급자 시뮬레이터 결과(`simulation: true`)로, FL은 `LOCAL_SIMULATION`과 실제 CSE 게시 결과로 표시하고 ESTIMED VM 배포는 대기 항목으로 표시함.
- 실물 검증 항목은 Pi Zero 2 W와 Feather ESP32 V2 벤치의 관측 저장, 전체 daemon 실행, LED 명령 ON/OFF와 GPIO readback 정산 기록에 연결함.

## 개인정보 점검 결과

- 팀원 실명이 키링 문서(`keyring/README.md` 담당자 줄, `keyring/firmware/README.md`, `keyring/pcb/*.md`, `keyring/raspberry-pi-gateway/*.md`), `contracts/keyring/README.md`, `docs/keyring-handoff.md`, `keyring/implementation-status.json`, `keyring/evidence/` 기록에 있음. 같은 이름의 로마자 표기가 옛 브랜치 이름과 `docs/branch-integration.md`, `docs/development-completion.md`, `.goalplz/`에 있음.
- 팀원 개발 PC의 사용자 경로가 키링 펌웨어와 Mobius4 개발 문서, `.goalplz/progress.md`, `keyring/evidence/` 로그에 있음. 다른 팀원 계정의 홈 경로가 `web-dashboard/evidence/hig/`의 검토 기록 2건에 있음.
- `docs/rubric-audit.json`에 팀원 머리글자로 적은 담당 기록이 있음.
- 위 항목은 2026-11-19 공개 main에 이미 같은 형태로 있음. 정리 범위는 팀이 정함.
- 이메일 주소와 실제 BLE MAC 주소 검색 결과는 0건임. IP 주소는 문서 예시 주소(192.0.2.10)와 Docker 내부 주소(172.17.x, 172.19.x)만 있음.
- 증거 폴더(`keyring/evidence/**`)는 `.gitattributes`에서 바이트 보존 대상이고 SHA-256이 기록되어 있으므로, 이름이나 경로를 지우면 기록된 해시가 바뀜. 정리 방식은 리드 판단이 필요함.

## 함께 확인한 문서 문제

- `keyring/dev/mobius4/README.md`가 `prepare.ps1`, `start.ps1`을 안내함. 저장소의 해당 디렉터리에는 compose, nginx, mosquitto, 인증서 생성, bootstrap 파일만 있음. 새 README는 이 디렉터리를 Docker Compose 참고 구성으로 소개함.
- `pc-mobius/contracts/raspberrypi-gateway.v1.json`의 `device.gateway` 값은 "Raspberry Pi 5"이고 실물 시험 장비는 Pi Zero 2 W임. README는 시험 장비 기준으로 적음.
