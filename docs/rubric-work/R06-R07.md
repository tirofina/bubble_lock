## R06 대응

- 저장소 지도의 모든 경로를 `git ls-files`와 파일 존재 확인으로 점검함.
- 빠른 시작 명령은 루트 `package.json`의 `setup`, `test`, `verify`, `demo`, `dashboard`, `events`, `api`와 `pc-mobius/package.json`의 스크립트 이름에 맞춤.
- Windows 준비 사항으로 `git clone -c core.autocrlf=false`와 `PYTHON` 지정(`py -3`)을 안내함. XSD SHA-256 불일치와 Store python stub 문제를 처음부터 피하는 방법임.
- 실제 CSE 실행 절차는 `MOBIUS4_ROOT`, `.local/postgres/connection.json`, `run-handover-real.mjs --keep-running` 뒤 `run-interop-real.mjs`, `run-acp-real.mjs`, `run-location-privacy-real.mjs` 순서로 적음.
- 배포는 Pi Gateway systemd 절차와 중앙 서버 구성(Mobius4, PostGIS, MQTT broker, 통합 API, 웹 BFF)으로 나눔.
- 검증 상태 표는 구현, 로컬 검증, 실물 검증을 분리함. MEC는 로컬 공급자 시뮬레이터 결과(`simulation: true`)로, FL은 `LOCAL_SIMULATION`과 실제 CSE 게시 결과로 표시하고 ESTIMED VM 배포는 대기 항목으로 표시함.
- 실물 검증 항목은 Pi Zero 2 W와 Feather ESP32 V2 벤치의 관측 저장, 전체 daemon 실행, LED 명령 ON/OFF와 GPIO readback 정산 기록에 연결함.
